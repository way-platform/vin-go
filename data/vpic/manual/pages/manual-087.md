## Engine: Turbo (lookup)

Column Names: EngineTurboId, EngineTurbo
Column Datatypes: tinyint, varchar(10)

Turbo is a yes/no field to identify whether the engine is turbo-charged or not.

| Attribute Name | Attribute Id |
| :------------- | :----------- |
| No             | 2            |
| Yes            | 1            |
