# Vehicle Identification Number (VIN) Coding Summary

**For Model Year 2023 Sprinter Vans**

## Manufacturer
Mercedes-Benz AG, Stuttgart/Germany

| VIN Position | Content |
| :--- | :--- |
| 1-3 | World Manufacturer Identification (WMI) |
| 4-5 | Model Type, Engine Type, Brake System, Model |
| 6 | Wheelbase, Body Length, Body or Chassis Type |
| 7 | GVWR Class, Chassis Configuration |
| 8 | Restraint devices and their location |
| 9 | Check Digit |
| 10 | Model Year |
| 11 | Plant of Manufacture |
| 12-17 | Vehicle Serial Number |
